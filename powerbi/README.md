# UK FMCG Store Network Performance: Power BI build notes

> **Project files are private.** The Power BI project (`.pbip`, report and semantic model folders) is not published in this repository. The interactive dashboards will be published separately for viewing, and the screenshots in [`docs/screenshots`](../docs/screenshots) show each page. This folder documents the build as text: the data model, Power Query and DAX measures.

## Files in this folder

| File | Contents |
| --- | --- |
| `Model.dax` | Every DAX measure in the semantic model, grouped by table |
| `WeeklySales.pq` | Power Query (M) for the `Weekly Sales` table |

## Report pages

### Retailer performance

- KPI cards: Net sales, Sales vs prior year, Sales vs target, Gross margin
- Line chart: Weekly sales and target
- Bar chart: Net sales by retailer
- Slicers: Retailer, Region

### Store network

- KPI cards: Stores, Net sales, Net sales per store, Sales vs target
- Bar chart: Store sales ranking
- Bar chart: Target variance by region
- Slicers: Retailer, Region, Format

### Category performance

- KPI cards: Net sales, Units sold, Gross margin, Promo sales share
- Bar chart: Net sales by category
- Bar chart: Promo sales share by category
- Slicers: Retailer, Region, Category

## Data model

| Table | Columns | Measures |
| --- | --- | --- |
| Weekly Sales | Week, Retailer, Region, Store, Format, Category, Units, Sales Pence, Prior Sales Pence, Target Pence, Profit Pence, Promo Pence | 10 |

The tables are independent. There are no relationships; each visual reads a single table.

## Rebuild

The model and report were generated by `scripts/build_powerbi.py`. Run it locally to recreate the Power BI project; the generated project files are kept out of version control.
