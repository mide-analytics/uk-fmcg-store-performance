## Calculated fields

| Field | Formula |
| --- | --- |
| Net sales | `SUM([sales_pence]) / 100` |
| Sales vs prior year | `(SUM([sales_pence]) - SUM([prior_sales_pence])) / SUM([prior_sales_pence])` |
| Sales vs target | `(SUM([sales_pence]) - SUM([target_pence])) / SUM([target_pence])` |
| Gross margin | `SUM([profit_pence]) / SUM([sales_pence])` |
| Stores | `COUNTD([store])` |
| Net sales per store | `SUM([sales_pence]) / 100 / COUNTD([store])` |
| Units sold | `SUM([units])` |
| Promo sales share | `SUM([promo_pence]) / SUM([sales_pence])` |
